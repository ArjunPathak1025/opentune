# OpenTune

Open-source Android music application combining local music playback with a provider-based online music experience.

## Current direction

- Kotlin + Jetpack Compose
- Android Media3 for playback
- Room for local library data
- Local and online music provider architecture
- Background playback and Android media controls

## Development

The Android foundation is currently being built on `feature/android-foundation` before merging into `main`.

## Principles

OpenTune aims to be privacy-respecting, open source, and provider-agnostic. Online music integrations will use legitimate APIs and services and will respect their terms and licensing.
