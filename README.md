# OpenTune

OpenTune is an open-source, self-hostable music library and player for music users own or are authorized to play.

## Project goals

- Fast, accessible web music player
- Personal music library with artist, album, and track metadata
- Playlists, favorites, queue, and playback history
- Local-first/self-hostable deployment
- Docker-friendly infrastructure
- Clean public APIs and contributor-friendly architecture

## Repository structure

```text
apps/       User-facing applications
services/   Backend and background services
packages/   Shared libraries and types
infra/      Deployment and infrastructure configuration
docs/       Architecture and developer documentation
```

## Development status

OpenTune is currently in the foundation phase. The initial milestone establishes the monorepo, engineering conventions, architecture, and development workflow before feature implementation.
